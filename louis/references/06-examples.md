# Louis examples

## Buttons

| Weak | Better | Why |
|---|---|---|
| I want to delete | Delete | The button sounds like the user's action |
| Saving | Save | Do not use the system's present tense |
| I understand | Got it | Standard confirmation without the extra "I" |
| OK | Continue | A specific verb is clearer |

## Forms

| Weak | Better | Why |
|---|---|---|
| Enter your phone number | Phone number | The label names the data, not the input action |
| Type a comment | Comment | Do not explain the field's obvious mechanics |
| Start typing | Search | Name the field or the action |
| Middle name | Middle name (optional) | Optionality must be visible on screen |

## Errors

| Weak | Better | Why |
|---|---|---|
| Oops! Something went wrong. Sorry about that | Couldn't load. Try again | Calm and actionable |
| Unfortunately, we couldn't load your data | We couldn't load your data | Drop the apologetic opener |
| An authorization error occurred | Sign in again | Give the user's action immediately |
| Invalid value | Enter 6 digits | Say exactly what to fix |

## Links

| Weak | Better | Why |
|---|---|---|
| Click here | See pricing details | The link names the destination |
| Read more | Open terms | The link names the action |
| This link | Message us | Drop the mechanics and show the result |

## Headings

| Weak | Better | Why |
|---|---|---|
| Important | Not enough funds | A specific heading explains the situation faster |
| Information | Request sent | The heading reports the state |
| Enter your phone number | Phone number | Do not instruct where the control is clear |

## Typography

| Weak | Better |
|---|---|
| 50 % | 50% |
| $ 10 | $10 |
| 1000 $ | $1,000 |
| December 14th, 2023 | December 14, 2023 |
| e-mail | email |
| click this link | See the guide |
| Save Changes | Save changes |
| "Done" | “Done” |
| 10 - 20 | 10–20 |
